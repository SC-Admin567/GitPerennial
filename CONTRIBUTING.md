Thanks for your interest in GitPerennial!

## Bug Reports and Questions

These are very welcome — please open an Issue.

To help diagnose your issue quickly, please include:

- Operating system and version (Windows/macOS/Linux)
- GitPerennial version (dashboard footer, or Settings → License)
- Free tier or licensed
- Which part of the app the issue occurred in (installer, background
  service, a specific dashboard tab, Settings, Archive, export/print)
  and the exact error message, if any
- Relevant excerpts from your Documents\GitPerennial\logs folder for
  that run (see Settings → Data locations for the exact path)
- Whether the issue is reproducible on re-run

The more detail you provide up front, the faster this can be tracked
down. **Never include your GitHub token, license key, checkout email,
or receipt number in an Issue** — those don't belong in a public bug
report; email support instead (see below) if anything sensitive needs
to be shared.

## Pull Requests

**GitPerennial does not accept code contributions, and this repo has
no source code to contribute to.** Unlike an open-source project
easing into outside contributions over time, this isn't a phase
GitPerennial will grow out of — GitPerennial is closed-source, paid
software. This repository holds only compiled installers (as GitHub
Release assets), documentation, and license terms.

If you have an idea for a fix or a new feature, please open an Issue
to discuss it — I read every one, and your input helps shape what
gets prioritized, even though there's no PR to merge.

## A Note on Support

This project is maintained by one person. I'll do my best to respond
to Issues in a reasonable timeframe, but please be patient — this
isn't a funded or staffed project. Purchasing a license doesn't come
with a specific response-time guarantee or phone support (see
[TERMS.md](TERMS.md) for the full terms).

Thank you for using GitPerennial, and for your patience as it grows.
